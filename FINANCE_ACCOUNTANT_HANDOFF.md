# Accountant handoff contract

The first version must export source-linked transactions, billing events, refunds, processor fees, affiliate payouts, expense entries, unresolved review items, and the configured base-currency assumptions for a selected period.

Exports must label the package as management records prepared for accountant review. They must preserve original currency amounts, never state that the system has determined tax liability, and include a questions list for missing evidence, FX, tax jurisdiction, or unusual transactions.
