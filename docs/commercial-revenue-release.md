# Commercial revenue release
The Sales Pipeline Commercial execution panel connects verified catalogue diagnostics, bounded Stripe checkout evidence, existing finance records, delivery scorecard, industry consultation paths, partner application, CRM tasks and direct proposals. Event totals are not unique users. Historical anonymous events must never be converted into fictional leads.
## Quote workflow
Create a lead-linked quote with current USD catalogue terms. Mark Sent only after reviewing; copy the customer link and share personally. Customer accepts the exact terms using their recorded email. Prepare a Stripe Checkout session after acceptance, then share the same proposal link; the customer confirms their email again to access payment. Paid webhook evidence is distinct from acceptance. Existing active website subscriptions use the account upgrade workflow. Legacy payment links require finance reconciliation.
## Pilot release gate
Conversion Sprint (one-time), Website Care (recurring) and agency delivery (individually scoped) are internal draft/interest paths. No public price or automatic launch. COMMERCIAL_PILOT_PAYMENTS_ENABLED must remain unset until owner approves commercial terms, cancellation/support policy, compatibility, fulfilment and test-mode payment validation. Super-admin approves each exact scoped quote; the signature binds the quote. Paid pilot fulfilment is tracked through access, delivery, review, delivered and closed/maintenance stages. No website entitlements granted by pilot payments. Website Care billing lifecycle must be reconciled before performing maintenance; cancellation and payment failures create operator tasks. Use Stripe for actual subscription management. Partner application reuses existing affiliate approval, attribution and payout controls; no new commissions are promised.
## Release acceptance
Run full CI and isolated Stripe test-mode scenario for accepted quote, failed/cancelled checkout, exact payment, duplicate webhook, recurring care renewal and cancellation. Verify production catalogue without mutation. Review role boundaries and existing test fixtures. Do not activate pilot flag, change catalogue prices, send marketing messages or deploy without release approval. Contribution and retention use existing measured delivery scorecard; incomplete data is not profit. CAC remains unavailable until acquisition spend and attributable paid customers are reconciled.
